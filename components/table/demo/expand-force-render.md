## zh-CN

使用 `forceRender` 在首次展开前挂载展开行内容。这对于需要提前注册的表单字段很有用。点击 `Validate fields` 可在所有行均为收起状态时校验这些字段。

## en-US

Use `forceRender` to mount expanded row content before the first expansion. This is useful for form fields that need to be registered in advance. Click "Validate fields" to validate them while all rows are still collapsed.

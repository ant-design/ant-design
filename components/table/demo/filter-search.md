## zh-CN

`filterSearch` 用于开启筛选项的搜索，通过 `filterSearch:(input, record) => boolean` 设置自定义筛选方法

本例中，搜索 Name 列的树形筛选项会高亮匹配节点；搜索 Address 列的菜单筛选项只会显示匹配项。

## en-US

`filterSearch` is used to enable search of filter items, and you can set a custom filter method through `filterSearch:(input, record) => boolean`.

In this example, searching the Name column’s filter tree highlights matching nodes. Searching the Address column’s filter menu shows only matching options.

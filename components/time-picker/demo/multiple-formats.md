## zh-CN

将 `format` 设为字符串数组，可以接受多种输入格式。输入 `14:30` 或 `1430` 并确认后，都会显示为 `14:30`。数组中的第一个格式决定显示格式和面板中的时间列。

## en-US

Set `format` to an array of strings to accept multiple input formats. Type `14:30` or `1430` and confirm the selection; both are displayed as `14:30`. The first format determines the displayed value and the time columns in the panel.

## zh-CN

设置 `scrollPosition` 属性，控制切换标签时激活标签的滚动对齐位置：`auto` 保持仅在溢出时滚到边缘的旧行为，`start` / `center` / `end` 将激活标签对齐到起始/居中/末尾，也可传 `0` 到 `1` 之间的数值作为对齐比例。

## en-US

Set `scrollPosition` to control the scroll alignment of the active tab when switching: `auto` keeps the legacy edge-aligned behavior, `start` / `center` / `end` align the active tab to the start/center/end, or pass a number between `0` and `1` for a custom alignment ratio.

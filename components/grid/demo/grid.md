## zh-CN

通过 `grid` 属性开启 CSS Grid 布局。`columns` 配置列数(默认 24,与 24 栅格心智一致),`areas` 配置模板区域,`Col` 用 `span`/`rowSpan`/`area` 定位;进阶场景(如网格线区间)可用 `style` 兜底。

## en-US

Enable CSS Grid layout via the `grid` prop. Use `columns` to set column count (defaults to 24, matching the 24-grid mental model), `areas` for template areas, and `Col` with `span`/`rowSpan`/`area` for placement. For advanced positioning (e.g. grid-line ranges), use `style` as the escape hatch.

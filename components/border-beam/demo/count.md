## zh-CN

通过 `count` 设置流光数量，`count` 应为正整数，多条流光会均匀分布在容器边框上。通过 `getItemConfig` 根据索引分别设置每条流光的 `color`、`lineWidth`、`outset` 和 `size`，也可以循环使用一组配置。未设置的属性会继承组件的同名属性。

## en-US

Use `count` to set the number of beams. `count` should be a positive integer, and multiple beams are evenly distributed around the container border. Use `getItemConfig` to configure each beam's `color`, `lineWidth`, `outset`, and `size` by index, or to cycle through a configuration pattern. Omitted item properties inherit the corresponding component props.

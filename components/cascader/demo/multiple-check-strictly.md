## zh-CN

通过 `multiple={{ checkStrictly: true }}` 开启父子节点独立选中模式，勾选状态不再联动（父节点选中不会自动勾选子节点，反之亦然），且不会出现半选状态，`showCheckedStrategy` 在该模式下不生效。

## en-US

Enable independent parent/child checking with `multiple={{ checkStrictly: true }}`. The checked state no longer conducts between parent and child nodes, no indeterminate state is shown, and `showCheckedStrategy` is ignored in this mode.

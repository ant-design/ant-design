## zh-CN

设置 `closable` 可显示默认关闭按钮，也可通过对象配置 `closeIcon` 和 `aria-label` 等无障碍属性。顶层 `closeIcon` 是简便配置方式，可设置自定义关闭图标或设为 `true` 显示默认关闭按钮。可关闭标签具有 `onClose` 事件，可通过 `e.preventDefault()` 阻止关闭。

## en-US

Set `closable` to show the default close button, or use an object to configure `closeIcon` and accessibility attributes such as `aria-label`. The top-level `closeIcon` is a shorthand for setting a custom close icon or showing the default close button with `true`. Closable tags support the `onClose` event. Use `e.preventDefault()` to prevent closing.
